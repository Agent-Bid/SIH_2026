# Waveform-choice model: training report

Generated by `ml/train.py`.

Data: 300,000 training scenarios (half with log-uniform range), 2 x 20,000 test scenarios with other seeds; labelled by the physics twin in 31 s.
Rule: finest profile that closes the link using at most max(4 x the cheapest working profile's energy, 1% of the ping's energy budget).

Training labels: X-S 35.2%, X-M 0.0%, X-L 0.0%, H-S 6.0%, H-M 0.0%, H-L 0.0%, M-S 6.8%, M-M 0.0%, M-L 0.0%, L-S 17.8%, L-M 4.2%, L-L 30.0%. In 28.2% of them no profile closes the link (best effort, L-L).

Agreement: same profile as the physics. Overridden: a profile can close the link but the ML's
pick either cannot or uses more energy than the allowance, so the physics replaces it
(FLAG_ML_OVERRIDDEN). Coarser: the ML's pick is kept but gives less detail than the physics'
(it then also uses less energy). Worst of the two test sets.

On the ESP32: neural net 6-48-48-n.
Per-class recall, uniform / log range: X-S 100%/100%, H-S 98%/99%, M-S 98%/98%, L-S 99%/99%, L-M 98%/98%, L-L 100%/99% (the other 6 profiles are never the rule's choice).
Best-effort cases where the ML also picks L-L: 99.87% / 99.73%.

## Amplitude

Network 12-48-48-1 (6 inputs + the profile, one-hot) predicting log(amplitude that just closes the link, before the 5% floor), trained on the 407,337 (scenario, profile) pairs where that amplitude matters, in 22 s; safety margin +0.0223 in log (x1.023), set so that 98 % of the uniform-range test picks above the floor need no raise. The firmware applies the floor.

| Test set | Amplitude error (median / 95th pct) | Raised by the physics | Extra energy vs just enough (median / mean) |
|---|---|---|---|
| uniform range | 1.77% / 3.46% | 1.69% | 3.57% / 3.41% |
| log range | 0.00% / 3.02% | 1.10% | 0.00% / 1.57% |

Amplitude error: |ML amplitude / amplitude that just closes the link - 1|, for the ML's own pick.
Raised: the ML's amplitude was short, so the physics raised it (FLAG_ML_AMP_RAISED). Extra energy:
what the ML's amplitude costs above the minimum (energy goes with amplitude squared).

float32 (as on the ESP32) vs float64: same profile on 100.00% of 6,000 vectors.
